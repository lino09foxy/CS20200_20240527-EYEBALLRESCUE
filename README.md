# CS20200_20240527-EYEBALLRESCUE
카이스트에서 열심히 눈알들과 공생하던 김눈알! 어느 날, 정체불명의 헌터가 나타나 눈알들을 잡아 병 속에 가두고 던전 안에 가둬 버렸다. 붙잡힌 눈알들을 구하기 위해 던전에 잠입한 김눈알! 숨겨진 함정들로 가득한 던전 속에서 김눈알은 무사히 눈알들을 구해낼 수 있을까?

Kim eyeball, who had been living happily alongside the Eyeballs at KAIST! One day, a mysterious hunter appeared, captured the Eyeballs, sealed them in a jar, and locked them away in a dungeon. Kim eyeball sneaks into the dungeon to rescue the captured Eyeballs! Will Kim eyeball be able to safely rescue the Eyeballs from the dungeon, which is filled with hidden traps?

------------------------------
## EyeballRescue
A simple game built with F#.
## Requirements
The project only requires the .NET SDK. All other package dependencies will be restored automatically.

* .NET SDK 8.0 (or higher)

## How to Run
Clone the repository and run the application using the .NET CLI.

# Clone the repository
git clone https://github.com[your-username]/[your-repo-name].git
cd EyeballRescue
# Run the project
dotnet run

The dotnet run command will automatically restore required dependencies, build the project, and start the game.
## Project Structure

* EyeballRescue.fsproj - Project configuration and dependencies.
* Program.fs - Main source file.
